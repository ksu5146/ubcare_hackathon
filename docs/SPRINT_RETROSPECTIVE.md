## 전체 회고

### 잘된 점
- 아키텍처 피벗(Sprint 5) 결정이 프로젝트 품질을 결정지음
- AI 인사이트 추가 구현이 핵심 차별화 요소가 됨
- URL 기반 필터 상태 + localStorage/DB 이중 패턴이 UX와 영속성 모두 충족
- 문서 선행 접근(PRD → 구현)이 방향 잃지 않게 도움

### 개선할 점
- mock 데이터 기능(주변분석)은 더 일찍 비활성화 판단했어야 함
- libSQL bigint 문제는 전환 초기에 일괄 검증했으면 반복 수정 불필요
- 테스트를 마지막이 아닌 기능 구현과 함께 작성했으면 더 좋았을 것
