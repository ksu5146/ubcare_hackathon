# PRD: 부동산 매수 도우미 포털

> **문서 버전:** v2.4
> **작성일:** 2026-03-13
> **갱신일:** 2026-03-15

---

## 1. 개요

대한민국 공공데이터를 활용하여, 부동산 매수 희망자가 자신의 조건에 맞는 매물을 탐색하고, 실거래가 추이를 비교 분석하며, 주변 호재/교통 등 입지 정보를 한눈에 파악할 수 있는 원스톱 부동산 분석 포털.

## 2. 타겟 사용자

- 실거주 목적의 아파트/연립 매수 희망자
- 첫 주택 구매를 준비하는 2030 세대
- 이사/이직으로 새 지역 부동산 시세를 파악하려는 직장인

## 3. 핵심 가치 제안

| 기존 문제 | 본 포털의 해결 |
|-----------|----------------|
| 여러 서비스를 왔다 갔다 | 가격대 설정 → 조건 필터 → 실거래가 추이 → 호재/교통 분석을 한 곳에서 |
| 실거래가 데이터를 직접 다운받아 엑셀로 분석 | 조건 입력만으로 자동 필터링 + 시각화 |
| 호재/교통 정보를 별도로 검색 | 매물 상세 화면에서 주변 정보 원클릭 확인 |
| 구 단위 검색 시 동마다 별도 조회 필요 | 사전 수집 DB로 구 전체 결과를 즉시 반환 |

## 4. 아키텍처 변경 요약

### v2.0 — DB 기반 아키텍처 피벗

**이전**: 사용자 요청마다 data.go.kr에 60건 이상 실시간 API 호출
**이후**: 수도권 3년치 실거래가를 DB에 사전 수집 → DB 조회로 즉시 필터링

| 항목 | 이전 (v1.0) | 이후 (v2.0+) |
|------|-------------|--------------|
| 검색 속도 | p95 2~5초 (API 레이턴시) | 즉시 (DB 쿼리) |
| 구 단위 검색 | 동 수 × API 호출 병렬 실행 | DB 쿼리 1회 |
| API 호출 한도 | 런타임 소비 | 배치 수집 시만 소비 |
| 필터 가능 항목 | 법정동 + 가격 + 면적 | 실거래가 32개 필드 + 단지 메타 전체 |

### v2.4 — 인프라 전환 및 자동화 완료

| 항목 | 변경 전 | 변경 후 |
|------|---------|---------|
| DB 엔진 | better-sqlite3 (로컬 파일) | Turso (@libsql/client, 엣지 호환) |
| 배포 모드 | standalone (Docker) | Vercel (서버리스, standalone 제거) |
| ODsay API 호출 | 서버 프록시 경유 | 브라우저 직접 호출 (도메인 기반 인증) |
| 증분 수집 | 수동 배치 스크립트 | Vercel Cron (매 1시간, 6개 지역 라운드 로빈) |

## 7. 데이터 수집 전략

### 수집 대상
- 서울 25개 구 + 경기 주요 시 (성남/수원/고양/용인/안양 등) + 인천 주요 구
- 기간: 최근 36개월
- API: 실거래가 `15126469` + `AptBasisInfoServiceV4/getAphusBassInfoV4` + `getAphusDtlInfoV4`

### 수집 단계
- Phase 1: 온디맨드/수동 배치 스크립트 (`scripts/collect.ts`) — 초기 수집 완료
- Phase 2: Vercel Cron 증분 업데이트 — **구현 완료** (매 1시간, 6개 지역 라운드 로빈)

### DB 인프라
- **Turso** (@libsql/client): 엣지/서버리스 환경 호환, 수도권 538,538건 수집 완료
- 스키마: `trades` + `complexes` + `trade_complex_map` 테이블, WAL 모드

## 9. 당초 계획 대비 추가 구현 사항

다음 기능들은 초기 기획(v1.0)에 포함되지 않았으나, 개발 과정에서 추가 구현되었다.

| 추가 기능 | 내용 |
|-----------|------|
| AI 인사이트 | Azure OpenAI 기반 수익률/실거주/자녀교육/미래가치 4개 영역 분석, 단지별 점수·장단점·키워드, 최종 추천, FAB 버튼 (bounce+glow 애니메이션) |
| 단지 스코어링 시스템 | 재건축가능성/주거쾌적성/미래가치 점수 계산 (`lib/collector/scoring.ts`) — 공공데이터 필드 기반 |
| 건물지표/단지평가 UI + InfoTooltip | 단지 상세 페이지 내 용적률·건폐율·에너지등급 및 스코어 시각화, 항목별 설명 툴팁 |
| Vercel Cron 자동 증분 수집 | 매 1시간 6개 지역 라운드 로빈 방식으로 최신 거래 데이터 자동 갱신 |
| 비교분석 가이드 오버레이 | Navbar 가이드 버튼 → 사용법 오버레이, 검색 페이지 첫 진입 시 튜토리얼 (오늘 다시 보지 않기) |
| 용적률Max 필터 (vlRatMax) | 고급 필터에 용적률 상한 슬라이더 추가 |
| 즐겨찾기 독립 데이터 패스 | 관심단지 지도가 검색 결과와 독립된 데이터 경로로 표시 |
| Ctrl+클릭 비교 선택 | 지도 마커에서 Ctrl+클릭으로 비교 단지 직접 선택 |
