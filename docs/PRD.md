# PRD: 부동산 매수 도우미 포털

> **문서 버전:** v2.3
> **작성일:** 2026-03-13
> **갱신일:** 2026-03-15

---

## 1. 개요

대한민국 공공데이터를 활용하여, 부동산 매수 희망자가 자신의 조건에 맞는 매물을 탐색하고, 실거래가 추이를 비교 분석하며, 주변 호재/교통 등 입지 정보를 한눈에 파악할 수 있는 원스톱 부동산 분석 포털.

## 2. 타겟 사용자

- 실거주 목적의 아파트/연립 매수 희망자
- 첫 주택 구매를 준비하는 2030 세대
- 이사/이직으로 새 지역 부동산 시세를 파악하려는 직장인

## 3. 핵심 가치 제안

| 기존 문제 | 본 포털의 해결 |
|-----------|----------------|
| 여러 서비스를 왔다 갔다 | 가격대 설정 → 조건 필터 → 실거래가 추이 → 호재/교통 분석을 한 곳에서 |
| 실거래가 데이터를 직접 다운받아 엑셀로 분석 | 조건 입력만으로 자동 필터링 + 시각화 |
| 호재/교통 정보를 별도로 검색 | 매물 상세 화면에서 주변 정보 원클릭 확인 |
| 구 단위 검색 시 동마다 별도 조회 필요 | 사전 수집 DB로 구 전체 결과를 즉시 반환 |

## 4. 아키텍처 변경 요약 (v2.0)

**이전**: 사용자 요청마다 data.go.kr에 60건 이상 실시간 API 호출
**이후**: 수도권 3년치 실거래가를 SQLite DB에 사전 수집 → DB 조회로 즉시 필터링

| 항목 | 이전 (v1.0) | 이후 (v2.0) |
|------|-------------|-------------|
| 검색 속도 | p95 2~5초 (API 레이턴시) | 즉시 (DB 쿼리) |
| 구 단위 검색 | 동 수 × API 호출 병렬 실행 | DB 쿼리 1회 |
| API 호출 한도 | 런타임 소비 | 배치 수집 시만 소비 |
| 필터 가능 항목 | 법정동 + 가격 + 면적 | 실거래가 32개 필드 + 단지 메타 전체 |

## 7. 데이터 수집 전략

### 수집 대상
- 서울 25개 구 + 경기 주요 시 (성남/수원/고양/용인/안양 등) + 인천 주요 구
- 기간: 최근 36개월
- API: 실거래가 `15126469` + `AptBasisInfoServiceV4/getAphusBassInfoV4` + `getAphusDtlInfoV4`

### 수집 단계
- Phase 1: 온디맨드/cron 배치 스크립트 (`scripts/collect.ts`)
- Phase 2: 일별 증분 업데이트 (최신 1개월만 재수집)
