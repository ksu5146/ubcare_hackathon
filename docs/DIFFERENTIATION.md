## 3. 핵심 차별 포인트

### 3.1 매수자 관점 특화

기존 포털은 **매물 중개/광고 수익**이 핵심 비즈니스 모델이다. 플랫폼의 이해관계가 중개사 및 광고주에 있기 때문에, 매수자가 정보 열위에 놓이는 구조적 문제가 있다.

본 프로젝트는 **매수자의 의사결정을 돕는 것**만을 목적으로 설계되었다.

| 구분 | 기존 포털 | 방구석임장 |
|------|-----------|-----------|
| 수익 모델 | 중개사 광고비, 프리미엄 구독 | 공공데이터 기반 (API 비용 없음) |
| 설계 목적 | 매물 노출 극대화 | 매수 의사결정 지원 |
| 데이터 투명성 | 중개사 제공 데이터 의존 | 정부 공공데이터 직접 활용 |
| 분석 깊이 | 시세 조회 위주 | 스코어링 + AI 인사이트 |

### 3.2 공공데이터 기반 무료 서비스

`data.go.kr` API 키 1개로 아파트 실거래가(538,538건), 단지 정보(8,813개)를 수집·제공한다. 별도 크롤링이나 유료 데이터 구매 없이 정부 공인 데이터를 사용하므로 **법적 리스크가 없고 데이터 신뢰도가 높다**.

수집 범위:
- 서울 25개 구 + 경기 주요 시(성남/수원/고양/용인/안양 등) + 인천 주요 구
- 최근 36개월 실거래가 538,538건
- 단지 기본정보 + 상세정보 8,813개 단지

### 3.3 16개 확장 필터 — 업계 최다 수준

대부분의 포털은 가격/면적/건축년도 3~5개 필터를 제공하는 데 그친다. 본 프로젝트는 DB에 수집된 공공데이터 필드를 그대로 필터로 노출하여 **16개 조건을 동시에 적용**할 수 있다.

| 필터 카테고리 | 항목 |
|--------------|------|
| 기본 | 가격 범위, 지역 (3단계 캐스케이드, 최대 3개 지역 동시), 전용면적 |
| 단지 특성 | 건축년도, 세대수, 층수, 시공사 |
| 건물 구조 | 난방방식, 복도유형, 승강기 유무, 분양형태 |
| 거래 조건 | 거래유형 (중개/직거래) |
| 편의시설 | 세대당 주차대수, 추정 방수 |
| 재건축 | 용적률 상한 |

### 3.4 2~4개 단지 동시 비교 + AI 인사이트

경쟁 서비스 중 단지 비교 기능을 제공하는 곳은 호갱노노(2개 제한)뿐이다. 본 프로젝트는 **최대 4개 단지를 10개 카테고리(기본정보/건물지표/단지평가/거래정보/주차/시설/교통/교육/편의시설/복리시설) 전 항목**으로 비교할 수 있다.

비교 후 **Azure OpenAI 기반 AI 인사이트**가 4개 관점(수익률/실거주/자녀교육/미래가치)으로 각 단지를 분석하고 최종 추천을 제시한다. 이는 국내 부동산 포털 중 유일한 기능이다.

비교 지원 항목:
- 기본정보: 위치, 건축년도, 세대수, 총 동수/층수
- 건물지표: 용적률, 건폐율, 에너지등급
- 단지 평가: 재건축가능성/주거쾌적성/미래가치 점수
- 거래정보: 최근 거래가, 시계열 오버레이 차트
- 주차/시설/교통/교육/편의시설/복리시설

### 3.5 단지 스코어링 시스템 — 재건축/주거/미래가치 자동 산출

호갱노노·아실 등이 연식이나 용적률을 단순 수치로 보여주는 것과 달리, 본 프로젝트는 **공공데이터 필드를 가중치 모델로 종합하여 0~100점 스코어**를 자동 산출한다.

| 스코어 | 구성 요소 | 가중치 |
|--------|-----------|--------|
| 재건축가능성 | 연식(45%) + 용적률 여유(40%) + 건물 상태(15%) | 30년+ 구축 시 재건축 요건 충족 플래그 |
| 주거쾌적성 | 주차비율(30%) + 건폐율(25%) + 용적률(20%) + 신축도(15%) + 부대시설(10%) | 최소 2개 지표 이상 시 산출 |
| 미래가치 | 연식에 따른 동적 가중치 (재건축/쾌적성 배합) + 용적률 여유 보너스 | 35년+ → 재건축 70% 반영 |

### 3.6 3대 업무지구 접근성 자동 계산

단지 상세 페이지에서 강남역·여의도역·광화문역까지의 **대중교통 소요시간, 환승 횟수, 예상 요금을 자동으로 계산**한다. ODsay API를 브라우저에서 직접 호출하고, DB에 저장된 단지 좌표를 그대로 전달하여 카카오 지오코딩 의존성을 제거했다.

직장 주소를 입력하면 해당 단지에서의 출퇴근 소요시간도 개인화하여 확인할 수 있다.

### 3.7 Vercel Cron 자동 증분 수집

별도 서버 없이 **Vercel Cron이 매 1시간마다 6개 지역씩 라운드 로빈 방식으로 신규 거래 데이터를 자동 수집**한다. 사용자는 항상 최신 실거래가를 별도 조작 없이 확인할 수 있다.

## 4. 포지셔닝 맵

```
                    분석 깊이 (높음)
                         |
         방구석임장 ●    |
                         |
매물 중개 ───────────────┼─────────────── 매수 분석
(낮음)                   |                    (높음)
                    아실 ●   호갱노노 ●
```

## 5. 타겟 사용자 적합성

| 시나리오 | 기존 포털 대안 | 방구석임장 강점 |
|---------|--------------|----------------|
| "강남 vs 마포 중 어디가 재건축 가치 높을까?" | 각 단지 별도 조회 후 수동 비교 | 단지 비교 + 재건축가능성 스코어 + AI 인사이트 |
| "회사까지 45분 이내인 아파트, 2억~5억, 500세대 이상" | 지역 범위 추측 후 수동 필터링 | 16개 필터 + 3대 업무지구 접근성 자동 계산 |
| "10년 내 재건축 기대 단지 찾기" | 연식 필터 + 용적률 직접 계산 | 재건축가능성 스코어 필터 + 용적률Max 필터 |
| "자주 쓰는 검색 조건 저장" | 미제공 | 필터 북마크 저장/불러오기 |
| "관심 단지 5개 비교 후 AI 추천 받기" | 각 탭에서 별도 확인 | 2~4개 동시 비교 + AI 인사이트 (FAB 버튼) |
