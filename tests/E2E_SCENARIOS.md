# E2E 테스트 시나리오

부동산 매수 도우미 포털의 주요 사용자 흐름을 검증하는 엔드-투-엔드 시나리오 문서입니다.
각 시나리오는 실제 사용자 관점에서 기술되며, 자동화 테스트(Playwright 등) 도입 시 기준 명세로 활용됩니다.

---

## 시나리오 1: 검색 → 필터 → 결과 확인

```
describe('검색 및 필터 흐름', () => {
  it('지역 선택 후 기본 검색 결과가 표시된다', () => {
    // Given: 사용자가 메인 페이지에 접속한다
    // When: 지역(예: 서울 강남구 역삼동)을 선택하고 검색한다
    // Then: 검색 결과 목록이 표시되고 결과 수가 1 이상이다
  });

  it('가격 필터 적용 시 결과가 줄어든다', () => {
    // Given: 지역 검색 결과가 표시된 상태
    // When: 가격 범위를 5억~10억으로 설정한다
    // Then: 결과 목록이 설정 범위 내 거래만 포함한다
  });

  it('면적 필터 적용 시 해당 면적 범위만 표시된다', () => {
    // Given: 지역 검색 결과가 표시된 상태
    // When: 면적을 84㎡~115㎡로 설정한다
    // Then: 결과 항목의 면적이 모두 설정 범위 내에 있다
  });

  it('필터 초기화 시 기본 결과로 복원된다', () => {
    // Given: 여러 필터가 적용된 상태
    // When: 필터 초기화 버튼을 클릭한다
    // Then: URL 쿼리스트링에서 필터 파라미터가 제거되고 기본 결과가 표시된다
  });

  it('활성 필터 개수 뱃지가 정확히 표시된다', () => {
    // Given: 검색 페이지
    // When: 가격, 면적, 층수 3개 필터를 순서대로 적용한다
    // Then: 필터 버튼에 뱃지로 "3"이 표시된다
  });
});
```

    // When: "카카오 로그인" 버튼을 클릭한다
    // Then: 카카오 OAuth 인증 페이지로 리다이렉트된다
  });

  it('로그인 후 로컬 즐겨찾기가 서버와 동기화된다', () => {
    // Given: 로그인 전 로컬에 즐겨찾기 3개가 저장된 상태
    // When: 카카오 로그인을 완료한다

## 실행 환경 및 도구

| 항목 | 내용 |
|------|------|
| 자동화 프레임워크 | Playwright (도입 예정) |
| 테스트 환경 | `http://localhost:3000` (개발 서버) |
| 브라우저 | Chromium (기본), Firefox, WebKit |
| 실행 명령 | `npx playwright test` (예정) |

현재 이 문서는 수동 QA 체크리스트 및 향후 Playwright 자동화의 기준 명세로 활용됩니다.
